# 🌌 GTA V Ultra-Realism & Survival Suite

> **"Code is meant to be free. Next-gen realism for everyone."**  
> *Engineered & Maintained by **Shadow***

An advanced, open-source C# script suite designed to transform Grand Theft Auto V into a hyper-realistic survival and physics experience. Built with a zero-crash architecture and optimized for ultra-high performance.

---

### 🎮 Controls & Features
* **NumPad 1:** Eat (+30% Hunger)
* **NumPad 2:** Drink (+35% Thirst)
* **NumPad 3:** Fuel & Repair Vehicle
* **NumPad 4:** Sleep/Rest (Time skip)
* **NumPad 9:** Toggle Mod ON/OFF

---

### 🛠️ Technical Stack
* **Language:** C# (.NET Framework 4.8)
* **API:** ScriptHookVDotNet3

*100% Free and Open-Source. Empowering the global modding community.*
